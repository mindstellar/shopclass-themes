# In-repo themes

This directory is the exception path, not the default one — see the root
[README.md](../README.md) and [CONTRIBUTING.md](../CONTRIBUTING.md#path-2-in-repo-hosting).
A theme that already has its own repository should be registered under
[`external/`](../external/) instead, so its releases stay where the author actually
publishes them.

Host a theme here only when it has no repository of its own. Each theme gets one directory,
`themes/<slug>/`, matching the shape in `docs/PACKAGE-SPEC.md` §1 in the
[mindstellar/shopclass](https://github.com/mindstellar/shopclass) repository.

No theme is hosted here today.
